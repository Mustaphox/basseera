# 🏗️ هيكلية ومعمارية منصة بصيرة (Architecture & System Design)

تعتمد منصة **بصيرة (Basseera)** على بنية برمجية خفيفة، معيارية، وفائقة السرعة مصممة بدون أطر عمل ضخمة (Vanilla PHP + Modern Modular Architecture) لتحقيق أقصى درجات الأداء والمرونة وسهولة الاستضافة.

## ⚡ محرك التخزين المؤقت والسرعة (Performance & Caching Engine)

1. **Local Disk Caching (`QuranApiService.php`)**:
   - يتم تخزين استجابات السور والقوائم على القرص في `cache/quran/` بصيغة JSON.
   - مدة بقاء الكاش (TTL):
     - نصوص السور: 30 يوماً.
     - قائمة السور: 7 أيام.
     - الآية العشوائية: ساعة واحدة.
   - انخفض زمن الاستجابة من **1200ms+** إلى أقل من **3ms**!

2. **In-Memory Static Caching (`get_setting`)**:
   - تخزين إعدادات الموقع في الذاكرة الثابتة لـ PHP لتفادي تكرار استعلامات MySQL في كل صفحة.

3. **HTTP Compression & Browser Expiry (`.htaccess`)**:
   - تفعيل `mod_deflate` لضغط ملفات HTML و CSS و JS و SVG عبر Gzip بنسبة توفير تصل إلى 75%.
   - تفعيل `mod_expires` لتخزين الخطوط والصور في متصفح الزائر لمدة عام كامل، والـ CSS/JS لمدة شهر.

## 🎨 نظام الألوان والسمات (Dual-Theme Color Engine)

يعتمد الموقع على نظام متغيرات CSS مخصصة (`CSS Custom Properties`) تدعم:
- **الوضع الليلي الفاخر (Dark Mode)**: خلفيات داكنة مريحة للعين `#0a0414` و `#150a2b` مع تباين ألوان كتابة عالية الدقة `#ffffff` و `#f8fafc`.
- **الوضع النهاري النقي (Light Mode)**: خلفيات مشرقة ناصعة مع خطوط بلون كحلي/رمادي داكن عالي الوضوح `#0f172a` و `#1e293b`.
- حفظ خيار السمة تلقائياً في `localStorage` مع سكريبت مانع للوميض (Anti-FOT) في ترويسة الصفحة.
